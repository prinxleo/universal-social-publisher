# Universal Social Media Publisher 🚀

A web-triggered desktop automation engine built with **Flask**, **Selenium**, and **Modern HTML/CSS**. Designed to automate content uploads and bypass modals across **TikTok Studio**, **Meta Business Suite**, **YouTube Studio**, and **Instagram Web** using your persistent Chrome profile.

---

## 🌟 Key Features
- **Modern Web Dashboard:** Clean, responsive UI with single-click manual triggers.
- **Session Persistence:** Uses existing Chrome profile sessions—no daily re-login required.
- **Anti-Detection:** Strips Selenium fingerprinting to bypass bot detection on Google & Meta.
- **Automated Modal Bypassing:** Auto-dismisses popups ("Got it", "Preview on phone", "Want to create ad post").
- **Smart Progress Tracking:** Waits for video processing before clicking active publish controls.
